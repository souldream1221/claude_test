# Icons

Place your application icons here:

- `32x32.png` - Windows taskbar icon
- `128x128.png` - Linux desktop icon
- `128x128@2x.png` - macOS Retina icon
- `icon.icns` - macOS icon bundle
- `icon.ico` - Windows application icon

You can generate icons from a PNG using Tauri's icon command:
```bash
npm run tauri icon /path/to/icon.png
```

Or use a simple placeholder for development.
